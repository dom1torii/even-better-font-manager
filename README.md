# Even Better Font Manager
EBFM - Cross-platform TUI tool that makes managing CS2 fonts easy. You can build a collection of fonts and change them with just a few presses of a button.

## How it works
EBFM basically just changes text inside config files for you. It takes the font you chose and copies it into `/game/core/panorama/fonts/custom/` and then edits `/game/core/panorama/fonts/conf.d/42-repl-global.conf` to replace all the fonts game uses to your font of choice.

## Can i get banned
No, it doesn't inject into the game and only changes publically available files that even say that they can be edited.  
Proof: [Original 42-repl-global.conf](https://domitori.xyz/5T0aE.png)
